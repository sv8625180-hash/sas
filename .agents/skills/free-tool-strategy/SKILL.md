# Estrategia de herramienta gratuita

## Objetivo

Decidir si una calculadora, generador, auditor, biblioteca o recurso gratuito resuelve un problema real y tiene una conexión legítima con la oferta principal. No asumas que atraerá tráfico, enlaces, leads o ventas.

## Flujo de trabajo

1. **Parte de un trabajo del comprador.** Describe usuario, tarea frecuente, alternativa actual, señal de dolor y resultado útil sin registro. Busca evidencia pública con `web_search`, verifica fuentes con navegador y anota contradicciones.
2. **Evalúa adyacencia y diferenciación.** Explica cómo la herramienta educa, ahorra trabajo o reduce incertidumbre antes de una oferta; compara soluciones existentes y sustitutos manuales. “No encontré resultados” no demuestra novedad.
3. **Calcula el coste total.** Incluye desarrollo, datos, modelos/API, moderación, abuso, seguridad, accesibilidad, alojamiento, mantenimiento y retirada. Usa Python para escenarios reproducibles si hay cifras, separando costes observados de estimaciones.
4. **Reduce el alcance.** Define un MVP que entregue un resultado útil, maneje fallos y no necesite recopilar datos personales. Decide si el resultado será abierto, con opción de guardar o con una puerta de captura solo después de evaluar consentimiento, valor de intercambio y obligaciones de privacidad.
5. **Define un experimento pequeño.** Establece la señal que validaría valor —uso completo, retorno, solicitudes cualificadas o entrevistas autorizadas—, una ventana, gasto máximo autorizado y criterio de parada. Si `agent_spawn` está disponible, úsalo solo para carriles independientes de demanda, alternativas y costes.

## Evidencia requerida

- Señales de problema y fuentes fechadas de demanda, alternativas y costes.
- Mapa de datos de entrada/salida, riesgos de privacidad y mecanismo de fallo seguro.
- Supuestos de distribución, captación y conversión marcados como hipótesis.

## Entregable

Entrega una ficha con problema, usuario, propuesta de utilidad, alternativas, conexión con la oferta, alcance MVP, costes/riesgos, plan de medición, criterio de parada y autorización requerida. Usa una matriz cualitativa transparente en vez de un umbral universal de puntuación o ROI.

## Límites

No construyas, alojes, publiques, gates contenido, recojas correos, envíes secuencias ni gastes en promoción sin autorización. No uses datos privados, afirmes beneficios financieros o prometas rendimiento SEO sin evidencia medida.
