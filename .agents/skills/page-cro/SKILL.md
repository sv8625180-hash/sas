# Optimización de conversión de página

## Objetivo

Encontrar fricciones y oportunidades en una página sin confundir una evaluación experta con evidencia causal. Identifica tipo de página, audiencia, fuente de tráfico, intención, acción primaria y el paso posterior de la experiencia.

## Flujo de trabajo

1. **Observa la experiencia real.** Usa el navegador para revisar desktop/móvil y el recorrido accesible; documenta URL, fecha, estado, elemento y captura cuando sea útil. Si hay analítica autorizada, pide definiciones, periodos, denominadores y segmentos antes de interpretarla.
2. **Evalúa el argumento y la fricción.** Revisa claridad de propuesta de valor, coherencia con la fuente de tráfico, jerarquía de CTA, prueba verificable, objeciones, formularios, rendimiento visible, accesibilidad y siguiente paso.
3. **Separa hallazgos de hipótesis.** Un botón poco visible es un hallazgo de interfaz; que aumentarlo mejore conversión es una hipótesis. Sin datos de comportamiento, limita el informe a problemas observables y experimentos propuestos.
4. **Prioriza con criterio explícito.** Para cada cambio, estima alcance, evidencia, riesgo, esfuerzo y dependencia; no uses una puntuación o una “mejora esperada” como hecho. Redacta variantes solo después de fijar el mensaje y la prueba disponible.
5. **Diseña validación.** Para cambios de impacto incierto, entrega hipótesis y medición para `ab-test-setup`; comprueba que el tracking puede medir el resultado completo, no solo clics intermedios.

## Evidencia requerida

- URL, dispositivo, fecha y elemento exacto de cada observación.
- Métricas con definición, intervalo y limitaciones, cuando existan.
- Fuente aprobada de cada prueba social, precio, garantía o afirmación propuesta.

## Entregable

Entrega una tabla de quick wins observables, cambios de mayor esfuerzo e hipótesis de prueba. Cada fila incluye problema, evidencia, segmento, mecanismo esperado, riesgo, esfuerzo, métrica y criterio de éxito o parada; añade alternativas de copy solo como borrador.

## Límites

No afirmes que una modificación elevará la conversión sin resultados representativos. No cambies una página pública, accedas a analítica privada, actives pop-ups, publiques copy ni inicies experimentos sin autorización.
